Install in under a minute

One copy-paste. Stash installs itself into Applications and opens.

  1. Open Terminal

    Press ⌘ Space, type Terminal, and press Return.

  2. Copy this and paste it into Terminal, then press Return
    curl -fsSL https://raw.githubusercontent.com/charliecurrin/stash/main/install.sh | bash

    It downloads about 110 MB and takes a minute or so.

  3. Sign in

    Stash opens by itself. Enter your email, type the 6-digit code we send you, and pick your @username.

After that, Stash updates itself. You'll see a Restart & Update button when there's something new.

Questions

Is it free?

Yes. Stash is free to download and use.

Why Terminal instead of a normal download?

Stash isn't on the App Store yet. The one-line installer is the quickest way to install it without macOS blocking it as an "unidentified developer". A regular download button is coming.

Which Macs does it work on?

Any Mac running a recent version of macOS, with Apple Silicon (M1 and later) or Intel.

Where is my stuff kept?

Your private notes and files are stored on your Mac. Only what you put in a shared section is synced, so the people in it can see it.

How do I uninstall it?

Quit Stash from the menu-bar icon, then drag Stash from your Applications folder to the Trash.
