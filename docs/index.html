Install Stash

One copy-paste. Stash installs itself into Applications and opens.

  1. Open Terminal

    Press ⌘ Space, type “Terminal”, then press Return.

  2. Paste this and press Return
    curl -fsSL https://raw.githubusercontent.com/charliecurrin/stash/main/install.sh | bash
  3. Sign in

    Stash opens by itself. Enter your email, type the 6-digit code we send, and pick your @username.

Stash isn't in the App Store yet, so this one-line installer is the cleanest way to install it without macOS warnings. To uninstall, drag Stash from Applications to the Trash.
